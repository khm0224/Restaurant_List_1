[06. 지도 코드에 사용된 JavaScript 문법]

============================================================
1. 화살표 함수 =>
============================================================

```javascript
response => !response.ok
```

일반 함수와 같은 의미다.

```javascript
function (response) {
    return !response.ok;
}
```

중괄호를 생략하면 오른쪽 계산 결과가 자동 반환된다.


============================================================
2. 부정 연산자 !
============================================================

!는 true와 false를 반대로 바꾼다.

```javascript
!true;  // false
!false; // true
```

따라서 다음 코드는 응답이 실패했는지를 뜻한다.

```javascript
!response.ok
```


============================================================
3. some()
============================================================

배열 요소 중 하나라도 조건을 만족하면 true를 반환한다.

```javascript
const hasFailure = responses.some(
    response => !response.ok
);
```

하나를 찾는 즉시 검사를 중단하므로 모든 요소를 끝까지 볼 필요가 없다.


============================================================
4. map()
============================================================

기존 배열의 각 요소를 변환해 새로운 배열을 만든다.

```javascript
const jsonPromises = responses.map(
    response => response.json()
);
```

responses 자체는 바뀌지 않고 JSON 변환 Promise 배열이 새로 만들어진다.


============================================================
5. forEach()
============================================================

배열의 각 요소에 대해 코드를 실행한다.

```javascript
restaurants.forEach(restaurant => {
    createMarker(restaurant);
});
```

map()과 달리 변환된 새 배열을 만드는 목적이 아니다.


============================================================
6. async와 await
============================================================

async 함수 안에서는 await를 사용할 수 있다.

```javascript
async function loadData() {
    const response = await fetch(DATA_URL);
    const data = await response.json();
    return data;
}
```

await는 Promise 작업이 끝날 때까지 해당 async 함수의 진행을 기다린다.
브라우저 전체가 멈추는 것은 아니다.


============================================================
7. Promise.all()
============================================================

여러 비동기 작업을 동시에 시작하고 모두 끝날 때까지 기다린다.

```javascript
const responses = await Promise.all([
    fetch(DISTRICT_URL),
    fetch(CITY_URL)
]);
```

첫 요청이 끝난 뒤 두 번째 요청을 시작하는 방식보다 효율적이다.
단, 작업 중 하나라도 거부되면 Promise.all()도 실패한다.


============================================================
8. 선택적 연결 연산자 ?.
============================================================

객체가 null 또는 undefined가 아닐 때만 다음 속성이나 함수를 사용한다.

```javascript
infoWindow?.close();
```

일반 코드로 표현하면 다음과 비슷하다.

```javascript
if (infoWindow !== null &&
    infoWindow !== undefined) {
    infoWindow.close();
}
```

지도 객체가 아직 생성되지 않은 상황의 오류를 줄여준다.


============================================================
9. Null 병합 연산자 ??
============================================================

왼쪽 값이 null 또는 undefined일 때만 오른쪽 값을 사용한다.

```javascript
const value = target?.latitude ?? target?.lat;
```

latitude가 없으면 lat 값을 대신 사용한다.
숫자 0이나 빈 문자열은 유효한 값으로 유지한다는 점에서 ||와 다르다.


============================================================
10. 구조 분해 할당
============================================================

객체나 배열에서 필요한 값을 바로 꺼낸다.

```javascript
restaurantMarkers.forEach(({ restaurants, marker }) => {
    marker.setMap(
        restaurants.some(matchesFilter) ? map : null
    );
});
```

각 배열 요소에서 restaurants와 marker 속성을 바로 꺼내 사용한다.


============================================================
11. 전개 문법 ...
============================================================

기존 객체의 속성을 새 객체에 복사한다.

```javascript
return {
    ...restaurant,
    distanceKm,
    distanceLabel
};
```

기존 음식점 정보는 유지하면서 거리 정보를 추가한다.


============================================================
12. 삼항 연산자
============================================================

```javascript
marker.setMap(visible ? map : null);
```

조건이 true면 `?` 뒤의 값을 사용하고,
false면 `:` 뒤의 값을 사용한다.

```javascript
if (visible) {
    marker.setMap(map);
} else {
    marker.setMap(null);
}
```

위 두 코드는 같은 의미다.
